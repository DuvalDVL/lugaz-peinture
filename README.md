# Site Lugaz & Fils (Jekyll, GitHub Pages)

1. Créer un dépôt GitHub, y envoyer tout ce dossier (glisser-déposer sur github.com).
2. Réglages > Pages > Source : « GitHub Actions ».
3. Chaque envoi lance `.github/workflows/pages.yml` : optimisation des images puis construction du site.
4. Photos : déposer les originaux (jpg/png) dans `assets/img/originals/`, nommés comme les emplacements du site. Un emplacement sans photo affiche un cadre gris.
5. Infos à corriger : voir `A_MODIFIER.md`.
